# Student-Grade-Mnagement-System-26BCE11340
 

## Project Overview

The Student Grade Management System is a simple Python-based console application designed to manage student academic records efficiently. It allows users to add student details, enter subject marks, calculate percentages, assign grades, and analyse class performance.

This project is developed using basic Python concepts such as dictionaries, loops, conditional statements, functions, and exception handling.

## Features

1. **Add a New Student** – Add student name, registration number, and marks in five subjects.
2. **View Student Details** – Display student information, total marks, percentage, and grade.
3. **Class Analysis** – Calculate the number of students and overall class average.
4. **Update Student Details** – Modify the marks of an existing student.
5. **Delete Student** – Remove student records using their registration number.
6. **Find Top Performer** – Identify the student with the highest percentage.
7. **Exit** – Close the application safely.

2. Download or clone this repository.
